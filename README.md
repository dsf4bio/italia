# Itália Sem Cidadania – Landing page

Pagina di vendita dell'ebook **Itália Sem Cidadania – Edição 2027** di Fabio Dos Santos (DS service).

- `index.html` – la pagina, un unico file HTML con gli stili inclusi
- `img/` – copertine, pagine di esempio dell'ebook (`img/pages/`), foto dell'autore, favicon e immagine per i social

## Sezioni della pagina
1. Hero con il libro 3D che segue il mouse (o l'inclinazione del telefono)
2. Linea del tempo della nuova legge sulla cittadinanza
3. Test interattivo "Qual é o seu caminho?" con il risultato a forma di carta d'imbarco
4. Galleria "Folheie antes de comprar" con 6 pagine reali
5. I 14 capitoli, i 7 bonus, l'autore
6. Prezzi (Guia R$87, Kit R$137), garanzia, FAQ e chiamata finale
7. Barra di acquisto fissa su mobile

I pulsanti di acquisto portano ai Payment Link di Stripe:

| Prodotto | Prezzo |
| --- | --- |
| Guia Prático | R$87 |
| Kit Completo | R$137 |

## Vedere la pagina in locale
Apri `index.html` nel browser, oppure in VS Code usa l'estensione **Live Server**.

## Pubblicarla online
Con **GitHub Pages**: Settings → Pages → Branch `main`, cartella `/ (root)` → Save. Dopo qualche minuto la pagina è online.
